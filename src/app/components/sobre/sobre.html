Sobre o Vaguinha

O Vaguinha é um projeto desenvolvido com o intuito de praticar desenvolvimento web com Angular. A ideia é criar um portal de vagas de tecnologia enquanto exploramos os conceitos aprendidos em aula.

O que estamos praticando?

  • Componentes reutilizáveis para cabeçalho, cards e rodapé.
  • Interfaces e tipagem de dados com TypeScript.
  • Exibição de listas, condições e eventos no template.
  • Comunicação entre componentes com inputs.
  • Layout responsivo e navegação por IDs.

Como experimentar

Consulte as vagas e abra os requisitos de cada card. Use o botão Entrar no início da página para favoritar vagas e se candidatar.
